### cuRAND 随机数生成库简介

官方文档：https://docs.nvidia.com/cuda/curand/index.html

**cuRAND** 库专注于简单、高效地在 GPU/CPU 上生成高质量的伪随机数（Pseudorandom Numbers）和准随机数（Quasirandom Numbers）。伪随机数虽然由确定性算法生成，但在统计分布上极其贴近真随机序列；而准随机数则旨在均匀填充高维空间（如蒙特卡洛采样）。

cuRAND 包含两个主要部分：
1. **主机端 (Host / CPU) 库**：包含头文件 `<curand.h>`。允许在主机端发起随机数生成请求，实际生成任务可以在 GPU 显存中并发完成（直接将随机序列保存在显存的全局内存中供自定义核函数使用），也可以直接在 CPU 内存中生成。
2. **设备端 (Device / GPU) 头文件**：`<curand_kernel.h>`。它定义了一系列可以在用户自定义核函数（Kernel）内部直接调用的设备端函数。允许每个线程在私有寄存器中独立初始化 RNG 状态并随用随产，无需将海量随机数先写回显存再读出，极大节省了显存带宽开销。

---

### 核心参数详解

- **种子 (Seed)**：
  - 一个 64 位整型参数，用于初始化随机数生成器的起始状态。相同的种子在相同的生成器算法下，必然产生完全一致、严格可复现的随机序列。

- **偏移量 (Offset)**：
  - 用于在当前随机序列中跳过前 $N$ 个结果。例如设置 `offset = 100`，则生成的第一个随机数对应整个理论序列中的第 100 个数字。这在多线程或多节点分布式并发生成时非常有用，确保各节点生成各自独立的随机片段而不产生重复。

- **数据排布 (Order)**：
  - 控制多维随机数在显存中的生成排布方式。详见 [cuRAND 主机 API 概览](https://docs.nvidia.com/cuda/curand/host-api-overview.html#order)。

### 深度学习框架（PyTorch）底层的 RNG 选型：
- **CPU 端**：PyTorch 主要采用 Mersenne Twister 的 **MT19937** 变体（对应 C++ 中的 `std::mt19937`）。
- **GPU 端**：针对 CUDA 操作，PyTorch 默认采用 **Philox** 算法。该算法计算密集度高、对状态存储需求极低，特别针对 GPU 的大规模并行架构进行了专门设计。

### 随机数生成的物理与计算本质：
要获得伪随机数，计算机通常需要两个要素：
1. **熵源 (Entropy Source)**：系统的不确定性输入（例如微秒级的时间戳、硬件噪声、芯片温度、时钟相噪等）。
2. **状态转移与混合算法 (Mixing Algorithm)**：通过精心设计的密码学或代数置换方程（如 XORShift、LCG、Philox、Counter-based 算法）将初始输入彻底打散，产生均匀且无相关性的伪随机比特流。
